=========================================================
OBJECTIVE
=========================================================

Implement a complete enterprise-grade Role-Based Access Control (RBAC) system.

The application has three primary roles:

• Citizen
• Officer
• Admin

The system must ensure that each role has access only to the resources and pages assigned to it.

=========================================================
BACKEND
=========================================================

Implement reusable permission classes.

Create

CitizenPermission

OfficerPermission

AdminPermission

AuthenticatedPermission

OwnerPermission (for resources owned by a user)

=========================================================
ROLE HIERARCHY
=========================================================

Citizen

Can

- Register
- Login
- View/Edit own profile
- Submit complaints
- View own complaints
- View notifications
- Give feedback

Officer

Can

- Login
- View assigned complaints
- Update complaint status
- Upload resolution proof
- View department dashboard

Admin

Can

- Manage users
- Manage officers
- Manage departments
- Assign complaints
- View analytics
- View reports
- Manage complaint categories
- Configure system settings

=========================================================
BACKEND PERMISSIONS
=========================================================

Protect every API endpoint.

Only authenticated users can access protected APIs.

Only Admin can

- Create officers
- Manage departments
- View system analytics

Only Officers can

- Update assigned complaints

Only Citizens can

- Create complaints
- Edit their own profile
- View their own complaint history
